📖 Descripción

Domeservice GT es una solución web diseñada para modernizar el comercio informal en Guatemala. Permite a trabajadores independientes gestionar inventarios y a clientes comprar productos locales de forma segura.

🚀 Funcionalidades Principales

Seguridad Multi-Rol: Accesos diferenciados para Administrador, Trabajador y Cliente.

Gestión de Inventario: CRUD de productos con imágenes en Base64 y descuentos.

E-commerce: Carrito de compras inteligente con cupones (ej. CHAPIN).

Soporte: Chat en tiempo real simulado con supervisión administrativa.

🛠️ Tecnologías Utilizadas (Arquitectura)

Frontend: HTML5, CSS3, JavaScript (Vanilla ES6+).

Backend: Node.js + Express (Simulado en prototipo).

Base de Datos: LocalStorage (Simulación NoSQL basada en Documentos).

📦 Instalación y Uso (Local)

Si deseas ejecutar este proyecto en tu máquina local, sigue estos pasos:

Clonar el repositorio:

git clone [https://github.com/](https://github.com/)[TU_USUARIO]/domeservice-gt.git


Instalar dependencias:

npm install


Ejecutar el servidor:

node app.js


Abrir en el navegador:
Visita http://localhost:3000
